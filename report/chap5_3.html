길동현

나의 역할

    뉴스 기사 API
    자원의 가격 변동 추이 그래프 그리기

느낀점

    소소한 기능을 구현하는 것도 많은 노력이 필요하다는 것을 느낌.
    많은 노력이 들어갔지만 그 노력에 비해 구현된 기능이 크게 차이가
    나지 않거나 버그가 너무 많이 생겨서 힘들었던 것 같습니다.

    팀플은 많이 해보지 않아서 서로 의견을 조율하는 과정 또한 힘들었음.

    처음으로 깃허브 기능을 팀플을 할 때 사용해 보았음. 이를 통해 왜 깃허브를 사용할
    줄 알아야 하는지 알게 되었음. 버전 관리 툴이 없었다면 프로젝트에 큰 혼란이 왔을텐데
    깃허브를 잘 활용하므로써 팀플을 무사히 끝낼 수 있었음.

    API기능을 처음 사용해 보았는데 API를 호출하는 빈도를 DB에 저장하는 방식으로 바꾸어 보았음.
    이러한 방법으로 API를 호출하는 횟수를 대폭 줄일 수 있게 되어 뿌듯함을 느낌.

결과평가

    주어진 기간 안에 해낸 프로젝트라고는 상상할 수 없을 만큼
    체계적이고 복잡한 프로그램을 만들었다는 생각에 뿌듯함을 느낌.
    그러나 시간이 너무 부족하여 추가하고 싶었던 기능을 모두 추가하지 못하여 아쉬움.

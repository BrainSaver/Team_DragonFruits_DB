■ 어떤 내용들을 수정하고 추가 할 것인가?

  • 수정할 내용들
    • 1. 양방향 로그인 기능

      • -> 구현의 난이도로 인해 단방향 로그인 기능으로 변경

    • 2. 철, 구리, 알루미늄 등의 전략 자원

      • -> API 값이 잘 불러와 지지 않고 부족해 철 삭제

    • 3. 뉴스 사진과 제목 간단한 내용 출력

      • -> 대시보드가 너무 난잡하고 공간 활용이 쉽지 않아 제목과 내용만 출력

      -> 내용만 추가하기 때문에 뉴스 디자인 변경

    • 4. 총 7개의 자원의 그래프와 시세 변동값 출력

      • -> 2번과 동일한 내용으로 금, 구리, 유가, 가스, 알루미늄으로 총 5개 자원으로 변경

    • 5. 이메일을 이용한 아이디, 비밀번호 찾기

      • -> 구현에 있어 리눅스, 24시간 서버, 시연 가능한 포트 개방 등의 복잡함이 있기 때문에 구현은 가능하나 삭제

    • 6. 비밀번호 찾기 삭제

      • -> 암호화 키를 관리할 수 없어 비밀번호 찾기 삭제

  • 추가할 내용들
    • 1. 회원 가입 시 이메일, 아이디, 비밀번호 입력칸 만들기
    • 2. 아이디 찾기: 이메일 입력 시 아이디 출력

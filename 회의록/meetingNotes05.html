회의내용

■ 어떻게 발표를 할 것인가?

  1. 발표 순서
    • 이재훈: 로그인 기능, ETF 소개
    • 구진근: 구글지도 및 원그래프 소개
    • 길동현: 뉴스 표시 및 자원 그래프 소개

■ 발표 내용

  1. 로그인 기능 보여주기 : 발표자가 서서 화면을 가리키며 로그인 기능에 대해 설명, 다른 한 명은 컴퓨터를 조작하여 로그인 및 로그인 실패 장면을 보여줌. 이후 ETF 설명.

  2. 로그인 된 대시보드 화면에 있는 구글맵의 마커와를 보여주고 원그래프를 설명함.

  3. 뉴스 페이지와 자원의 가격 변화 그래프에 대한 설명을 함.

    ■ 예상 질문

  1. 어떤 API를 사용하셨나요? : Fred와 NewsApi, GoogleMap API를 사용하였습니다.

  2. 실시간 데이터 인가요? : 실시간은 아니지만 사이트를 켤 때 최신의 데이터를 가져올 수 있습니다.

  3. 데이터는 어떻게 불러오나요? : Api를 통해 json 형식으로 저장된 데이터를 DB에 저장한 뒤 DB에 저장된 데이터를 불러와서 표시하는 방식을 사용하였습니다. 이렇게 하면 Api 호출 빈도를 줄여 비용 절감에 도움이 되기 때문입니다.
